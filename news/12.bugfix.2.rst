``ical_to_jscal`` and ``jscal_to_ical`` now use ``recurrenceRule``/``excludedRecurrenceRule`` (singular) instead of RFC 8984's actual ``recurrenceRules``/``excludedRecurrenceRules`` (an array). Neither Cyrus nor Stalwart accept the array shape; both use the older singular property on create, update, and read. Any recurring event previously failed outright against both servers. Only the first RRULE/EXRULE is kept when a VEVENT has more than one, a rare case in practice.
